## Full description

(4000 characters max)

```
RepoGlance is a home-screen widget for keeping an eye on your GitHub
repositories — no need to open an app or a browser tab to check in.

Add a RepoGlance widget to your home screen, pick the repositories you care
about, and glance at their stats whenever you check your phone. RepoGlance is
read-only: it never opens issues, pushes commits, or changes anything in
your repositories. It just shows you what's there.

Sign in with your GitHub account using GitHub's own official device-code
sign-in flow — the same kind of flow GitHub uses for CLI tools and other
trusted integrations. RepoGlance talks directly to GitHub's API from your
device to fetch live data; there is no separate RepoGlance server in the
middle. Your GitHub access token is stored only on your device and is never
sent anywhere except to GitHub.

RepoGlance contains no ads, no analytics, and no third-party trackers.

RepoGlance is open source. You can read the code, file issues, or contribute
at https://github.com/saari-co/RepoGlance.
```
